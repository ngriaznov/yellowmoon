# data/looks/builtin/

Built-in looks as JSON parameters (`yellowmoon.parametric-look/1`, see `docs/08-looks.md`):

- `neutral.json`: the identity (M1-10). Neutral also exists in code, so the app works without this folder.
- `signature.json`: designed by Mykyta (M3-10, HUMAN M3-H1). **Not shipped yet.** The library lists exactly the files that are here, so Signature appears the day the file does.

Any other `*.json` here is listed as `builtin:<file name>`. No ARRI data ever goes here.
