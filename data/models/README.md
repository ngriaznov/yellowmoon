# data/models/

Model weights shipped in the app bundle, one folder per model (`jdd/`, `illum/`, `crop/`, optionally `jdd-ms/`, `smap/`), each with its weights, SHA-256 and `MODEL_CARD.md`. `illum/` ships since M1-06 and `crop/` (Auto crop's crop model, `docs/20-auto-crop.md` §6) since 2026-10-23; `jdd/` is empty until M2-06. See `docs/07-ml-models.md`. `bokeh/` (the bokeh map network of lens character, `docs/21-lens-character.md` §7, run by `ym_ml::bokeh_net`) is pending: the runtime, its parity tests and the dev example exist, and the weights (`bokehnet.safetensors`, `SHA256SUMS`, `MODEL_CARD.md`, about 6 MB in f32) are committed here once the model passes the go/no-go of `training/bokeh/README.md`; the parity fixture goes to `crates/ym-ml/tests/data/bokehnet_parity.json`. Licence of the weights: Apache-2.0, as the repository (our own network trained from scratch with our own code in `training/bokeh/`, no pretrained weights; the training data's licences are in `training/bokeh/README.md`, and the photos' credits go in `NOTICE` and the model card with the weights). The folder exists from the start because `tauri.conf.json` bundles it.
