# data/models/

Model weights shipped in the app bundle, one folder per model (`jdd/`, `illum/`, `crop/`, `bokeh/`, optionally `jdd-ms/`, `smap/`), each with its weights, SHA-256 and `MODEL_CARD.md`. `illum/` ships since M1-06 and `crop/` (Auto crop's crop model, `docs/20-auto-crop.md` §6) since 2026-10-23; `jdd/` is empty until M2-06. See `docs/07-ml-models.md`. `bokeh/` (the bokeh map network of lens character, `docs/21-lens-character.md` §7, run by `ym_ml::bokeh_net`) ships since 2026-10-25: `bokehnet.safetensors` (model `bokeh-3`, 6,100,536 bytes, f32, batch norms folded, 1,522,122 parameters), `SHA256SUMS` and `MODEL_CARD.md`; its parity fixture is `crates/ym-ml/tests/data/bokehnet_parity.json`. Licence of the weights: Apache-2.0, as the repository (our own network trained from scratch with our own code in `training/bokeh/`, no pretrained weights; trained on Open Images photos listed as CC BY 2.0 and their CC BY 4.0 masks, credited in `training/bokeh/CREDITS.tsv.gz`, the model card and `NOTICE`). The training checkpoint (`model.pt`) is not part of the repository. The folder exists from the start because `tauri.conf.json` bundles it.

`sam2/` (SAM 2.1 small, the Object mask of `docs/23-nodes.md` §4.4, run by our own runtime, N-17) holds `MODEL_CARD.md`, `SHA256SUMS` and a `.gitignore`: its weights (`sam2.1_hiera_small.f16.safetensors`, the image path only, 38.5 million parameters, about 77 MB) are too big for git, so they are published as an asset of the prerelease `models-sam2.1-small-1` by `.github/workflows/models.yml` and fetched by `tools/fetch/sam2.sh` (pinned by SHA-256) into this folder, by the build before the app is bundled. Licence: Apache-2.0 (Meta Platforms, Inc. and affiliates; `NOTICE`).

`mediapipe/` (BlazeFace full range, Face Mesh V2 and Selfie Multiclass 256, Google's MediaPipe networks for the Skin node, `docs/27` S-08, run by `ym_ml::mediapipe`) holds `MODEL_CARD.md`, `SHA256SUMS` and a `.gitignore`: its three weights files (`blaze_face_full_range.f16.safetensors`, `face_mesh_v2.f16.safetensors`, `selfie_multiclass_256.f32.safetensors`, about 20 MB in all) are not committed, they are published as assets of the prerelease `models-mediapipe-faces-1` by `.github/workflows/models.yml` (job `mediapipe`) and fetched by `tools/fetch/mediapipe.sh` (pinned by SHA-256) into this folder, by the build before the app is bundled. Licence: Apache-2.0 (Google; `NOTICE` item 14).
